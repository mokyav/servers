# Koruva 26.3 統合・復旧ノート

更新日: 2026-11-22

## 対象アーカイブ

- `koruva-current-progress-cycle28-2026-11-21.zip`
- `koruva-fixed-26.3-stage6-vanilla(1).zip`
- `koruva-26.3-mob-texture-position-fix.zip`

## 統合方針

Mob修正版の26.3データ・テクスチャ・Mob描画を基礎にし、Stage 6のブロック状態・モデル・設置破壊関連を接続。Cycle 28の追加機能は、ファイルの存在だけでなく現行のクライアント／Worker／保存方式から呼び出されるかを確認して移植した。同名ファイルは一括上書きしていない。

## 今回復旧・追加した機能

### 死亡・経験値・ドロップ
- 経験値の死亡ドロップ量を現在レベルに応じて計算（7ポイント/レベル、最大100）。
- サバイバル／アドベンチャーで所持アイテムと装備スロットの数量をワールドドロップへ変換。
- 経験値オーブの生成・描画・近接回収・経験値加算をサーバー権威で接続。
- XPオーブはアイテムIDなしの独立ドロップとして保存・再読み込みできるよう修正。
- ドロップの残量、アイテム数量、経験値を保存し、満杯時には一部だけ回収して残量を保持。

### Mob素材
- 骨、矢、火薬、糸、クモの目、エンダーパール、ブレイズロッド、ガストの涙、スライムボール、マグマクリーム、プリズマリン素材、銅インゴットの限定テーブルを復旧。
- 対応するMobを近接攻撃／飛び道具で倒した際、素材を実際のワールドアイテムドロップとして生成。
- **制限:** 元Cycle 28のテーブルも試作的な部分集合であり、26.3の完全なLoot Tableではない。環境死・コマンド死など全ての死亡経路にも接続済みとは扱わない。Lootingや各Mobの条件別確率も完全互換ではない。

### クラフト
- 作業台の3×3入力UIを復旧し、レシピ選択時は実際の3×3枠に材料を配置する方式に変更。
- オンラインではWorker側で作業台ブロックの存在、設置距離、レシピの形状・材料配置、所持材料を検証。
- プレイヤーインベントリ内の2×2クラフトは4枠に制限し、3×3専用レシピを拒否。
- ソロ保存に作業台グリッドを含める。

### その他
- 旧64×32スキンの左右腕・脚UVを面単位でミラーし、既存の全体コピー処理を置換。
- 現行のスタック単位耐久データをホットバー／インベントリにバー表示し、耐久値の残量・色・ツールチップを反映。
- 旧形式の耐久・採掘ヘルパーを互換APIとして復旧。現行ゲームの実耐久処理はスタック単位の `damageStackRecord` を維持。
- 異なるディメンションで採掘開始した際、Overworldではなく現在のディメンションのブロックを参照するよう修正。
- Solo保存データのスタックコンポーネント構造を検証し、不正なslot key、item/count/damage値を拒否。

## 既知の制限・未完了

- 死亡ドロップのItem Stack NBT（個別耐久、エンチャント、名前、修繕コスト等）はドロップEntityにまだ保持されない。死亡時にslot metadataをクリアする。
- XPの死亡ドロップは一つのXPオーブEntityにまとめる簡易方式で、Vanillaの複数オーブ分割・移動・吸引演出とは異なる。
- Mob素材ドロップは限定Mob／限定アイテムの試作テーブルで、26.3全Loot Table、Looting、環境死などを網羅しない。
- 3×3グリッドはクライアント側で配置状態を持ち、オンラインではCraft要求時にサーバーがグリッド・作業台・距離・所持材料を検証する。切断中の未確定グリッド状態をサーバー側で独立永続化するものではない。
- 石切台・鍛冶台・村人取引・全コンテナ、全Mob固有AI、完全な水／溶岩・照明・Redstone、全ブロック状態／Biome tint、全GUIアニメーションは未完成または未検証。
- 384ブロック高のJava版ワールド、地形生成・構造物・Mobシミュレーションの完全なJava parityは未達。

## ビルド前の注意

`node_modules` は配布ZIPに含めていない。通常のNode/npm環境で `npm ci` を実行してから `npm test`、`npm run build` を実行すること。ビルド成功と実プレイ動作確認が終わるまでは、本番公開可能な完成版として扱わない。
