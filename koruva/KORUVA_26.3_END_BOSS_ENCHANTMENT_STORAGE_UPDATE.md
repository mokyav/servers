# Koruva 26.3 — 保存・エンチャント・戦闘・エンド更新

更新対象は、ユーザー提供の Koruva プロジェクトと `client.zip` 内の Minecraft Java 26.3 データです。

## 今回までに追加・接続した内容

### 1. アイテム個別保存／金床／砥石
- アイテム種類ごとの合算ではなく、インベントリの各スロットに個別スタックデータを保存。
- エンチャント、耐久値、修理コスト、カスタム名、装填済み投射物をスタック単位で保持。
- Durable Object の `stack-data:<player id>` に保存し、再接続時に復元・検証。
- 金床：同種アイテムの修理／合成、エンチャント本の合成、名前変更、経験値コストと高コスト制限。
- 砥石：呪い以外のエンチャント除去、同種アイテム修理、経験値返却。
- 保存値はサーバー側で検証し、クライアントからの未検証スタックデータをそのまま採用しない。

### 2. エンチャント
- Minecraft 26.3 の43種類のエンチャント定義、最大レベル、アイテム互換性、排他関係を収録。
- エンチャントテーブルの周囲1ブロック空間を含む本棚配置を検査し、最大15パワーを計算。
- ラピスラズリ・経験値レベル・付与可能アイテムをサーバー側で検証。
- 戦闘、採掘、耐久、移動、弓／クロスボウ／トライデント、槍／メイスに既存の対応効果を接続。
- 実装されている主な効果：ダメージ増加系、アンデッド／虫／水生特効、ノックバック、火属性、範囲攻撃、効率強化、幸運、シルクタッチ、耐久力、修繕、防具保護、棘の鎧、氷渡り、水中歩行、ソウルスピード、スニーク速度、弓の射撃ダメージ／パンチ／フレイム／無限、クロスボウの高速装填／マルチショット／貫通、トライデントの忠誠／激流／水生特効、メイスの重撃／防具貫通／ウィンドバースト、槍の突進。

### 3. 弓・クロスボウ・トライデント・採掘ツール
- 弓のチャージ量、パワー、パンチ、フレイム、無限の矢消費処理。
- クロスボウの高速装填、マルチショット、貫通のサーバー発射処理。
- トライデントの投擲、忠誠による帰還、激流による水中推進、水生特効ダメージ。
- ピッケル／斧／シャベル／クワの適性・採掘速度・効率強化・幸運・シルクタッチ・耐久処理。

### 4. エリトラ
- サーバー側で滑空状態、移動速度、衝突、耐久消耗、ロケット加速を検証・補正。
- エンチャントされたエリトラの耐久力／修繕を反映。
- これは Koruva 用の決定的な飛行モデルであり、Minecraft Java の全ての物理境界条件と完全一致するものではない。

### 5. ディメンション／エンドラ戦
- Overworld、Nether、End のディメンション別チャンク・Mob・投射物・プレイヤー処理。
- エンド中央島の黒曜石柱、鉄格子ケージ、外島と簡易エンド構造物。
- Ender Dragon：200 HP、サーバー管理の旋回／ストレイフ／急降下AI、ドラゴンファイアボール、接触攻撃。
- End Crystal：破壊可能なエンティティ。生存中の近隣クリスタルがあるとドラゴンを毎秒1 HP回復。
- ドラゴンブレス／クリスタル爆発は距離減衰、プレイヤー防具軽減、ノックバック、および周囲Mobへのダメージに対応。
- 討伐状態を永続化し、中央の帰還ポータル、ドラゴンの卵、エンドゲートウェイを生成。
- Ender Dragon と End Crystal の専用モデル／表示を追加。

## 未完成・Java版と異なる点

このZIPを「Minecraft Java 26.3 の完全再現」とは扱えません。重要な未対応点は次のとおりです。

- Channeling：投げたトライデントの `channeling` 情報は保持しますが、天候／雷雨条件を持つワールド天候システムと雷撃そのものは未実装です。
- Luck of the Sea／Lure：釣り竿・釣りミニゲームが未実装のため、現状は定義と互換性中心です。
- Binding Curse／Curse of Vanishing：エンチャントデータは保存されますが、装備解除禁止・死亡時消滅の全ルールは未完成です。
- クロスボウの花火ロケット装填・爆発、Punch のプレイヤーへのノックバックなど、投射物の一部相互作用は未完成です。
- エンドラのバニラ準拠ボスバー、厳密な着地／止まり木フェーズ、エンドクリスタル4個によるドラゴン再召喚儀式、中央／外島ゲートウェイの完全な往復処理は未実装です。
- ドラゴンの移動・衝突・回復・爆発はKoruva用の近似実装で、バニラの全攻撃判定・ビーム・ダメージ曲線を再現したものではありません。
- 金床／砥石／エンチャントテーブルはサーバー処理が接続されていますが、Java版の画面・操作・確率・コスト計算を全ケースで完全一致させたものではありません。
