# Koruva — Minecraft Java 26.3 データ・ワールド拡張

## 参照したデータ

同梱された Minecraft Java Edition 26.3 クライアントのデータを読み取り、データパック形式 121.0 / データバージョン 5023 を基準に取り込みました。これは公式クライアントのデータ定義を参照した拡張であり、Minecraft本体の生成エンジンやJavaコードを移植したものではありません。

## 追加・接続したデータ

- **バイオーム：67種類** — 気温、降水、地表・水色などの効果情報、特徴生成リスト、カーバー、自然Mobスポーン表を登録。
- **構造物：52定義** — structure JSON、structure set 21件、jigsaw用template pool 245件、NBTテンプレート1,511件を同梱。
- **ワールド生成データ** — configured/placed feature（240 / 273件）、structure set（21件）、template pool（245件）、noise（64件）、density function（55件）、material rule（42件）、タグなど、26.3のワールド生成データを `src/client/public/data/minecraft/worldgen` に収録。
- **ディメンションタイプ：4定義** — Overworld、Overworld Caves、Nether、Endの設定データを収録。プレイ可能なディメンションは既存どおりOverworld / Nether / Endの3つです。
- **ブロック・アイテム** — 26.3クライアント側のブロック状態1,288件、ブロックモデル2,883件、ブロックテクスチャ1,405件などを同梱。Koruvaの既存ランタイムIDカタログ（ブロック1,288・アイテム1,658）は維持しています。
- **Mob：88種類** — 既存のMobプロファイル88件を維持し、26.3の自然スポーン定義をバイオーム別に利用できるようにしました。`naturalMobSpawnEntries()` では ambient / creature / monster / 水中系などのカテゴリーも参照できます。

## 実際のゲーム処理に追加したもの

- 新規ワールドの生成バージョンを **3** に更新。気候に応じた複数の地上バイオーム、海岸・海洋、山岳、森林系の選択を追加。
- 洞窟内に lush caves / dripstone caves / deep dark / sulfur caves の簡易生成を追加。
- バイオームに応じて砂・雪・泥・菌糸・各種木材と葉の種類を変更。
- 地上に村、砂漠のピラミッド／井戸、イグルー、ジャングル寺院、廃キャンプ、荒廃したポータル、沼地の小屋、前哨基地、難破船、海底遺跡、廃坑、要塞、古代都市、試練の間、海底神殿、森の洋館などの簡易プロシージャル構造を追加。
- Netherに砦／砦の遺跡／ネザー化石の簡易構造、Endの外島にエンドシティ風構造を追加。
- 攻撃チャージとサーバー側ダメージ計算は元から存在するため維持。26.3の追加武器として検出できるよう、spear / mace / copper axe の武器分類とチャージ間隔を追加（spear 17 ticks、mace 22 ticks、copper axe 22 ticks）。これらはKoruva側の調整値で、Java版の全武器挙動を再現するものではありません。
- 既存ワールド保護のため、ワールド生成バージョン1・2は旧生成処理を維持。新規ワールドのみバージョン3を使用。

## 重要な再現範囲・制限

- 67バイオームすべての**定義データ**を収録していますが、現在の簡易気候生成器が毎回67種類すべてを出現させるわけではありません。
- 52構造物の定義とNBTテンプレートは同梱していますが、NBTのジグソー接続や公式テンプレート配置を完全に実行する仕組みはまだありません。実際の新規生成は複数の構造物ファミリーを簡易ブロック形状で配置します。
- Koruvaのチャンク形式は現在 **高さ128ブロック**です。公式ディメンションタイプの高さ（Overworld 384、Nether/End 256）とは一致させていません。
- 88種のMob IDとAIプロファイルは登録済みですが、Mobごとの固有AI・アニメーション・専用3Dモデルすべてが完成したわけではありません。現在のAIは受動／近接／遠距離／爆発などの共通挙動を使用し、見た目も一部モデルの色替え・共通形状です。
- ブロックIDとアセットは揃っていますが、Java版と同じ全ブロック状態・全当たり判定・全レッドストーン挙動まで完全一致するという意味ではありません。

## 確認結果

- `node --test test/*.test.mjs`：**192件成功 / 192件**。
- 旧ワールド生成v1のチャンクSHAテスト、およびv2の決定性・地形テストを維持。
- 26.3バイオーム67件・構造物52件の登録と、新規ワールド生成v3の決定性をテスト。
- TypeScript / Viteのフルビルドは依存パッケージ未導入の環境では未確認です（このZIPに `node_modules` は含めていません）。


## 2026-11-21 追加更新：高さ・照準・採掘・エンティティ・サバイバルレシピ

- **ワールド高さを128に変更**。共有定数、チャンク配列サイズ、描画上限、クライアント設置・スポーン検証、サーバー編集・テレポート・Mob地形判定を同じ高さ上限に統一。既存セーブは読み込み時に新しいチャンク容量へ正規化されます。
- **ブロック照準判定を形状対応に変更**。raycastは1/32ブロック間隔で進み、衝突・メッシュと共用の4×4×4占有マップを使ってハーフブロック、階段、薄い形状等の空洞を通り抜けないようにしました。Java版の全state hitboxそのものではなく、Koruvaの形状近似解像度です。
- **採掘中のひび割れ表示**。26.3クライアントの`destroy_stage_0..9`を採掘進捗に合わせて表示。現状オーバーレイはブロック立方体を基準としているため、部分形状ではひび割れ範囲が完全一致しません。
- **スケルトン／ストレイの矢**。即時遠距離ダメージから、重力を受けるサーバー権威の矢エンティティへ変更。矢の位置・速度・寿命・ブロック衝突・プレイヤー/Mobへの命中判定をサーバーが処理し、同じディメンションの接続プレイヤーへ配信。矢とMob状態はDurable Objectストレージへ保存します。
- **クラフトデータ**。26.3のクラフトレシピ1,234件を候補アイテム（タグ展開）付きで取り込み、既存カスタム分を含む1,247件をランタイムで利用。マルチプレイではWorkerが材料・レシピ照合と消費を実施します。
- **加工データ**。26.3の加工レシピ479件（石切台351、かまど73、溶鉱炉25、燻製器9、焚き火9、鍛冶変換12）を取り込み。燃料時間と決定論的なかまど状態遷移関数を実装し単体テスト済み。

### 今回も未完成の機能（完成扱いにしない項目）

- 構造物のNBTテンプレートは保持していますが、Jigsaw template poolをルールどおり接続して複数パーツを完全配置するエンジンは未実装。現行の生成はプロシージャルな簡易構造です。
- 88種のMobすべての専用AI・挙動・モデルを実装したわけではありません。共通AIが残り、専用の物理矢はSkeleton/Strayが対象です。矢のアイテム化・回収、盾での防御、全エンティティ種類との衝突、各Mob固有ドロップ/経験値連携なども未完了です。
- 加工レシピ479件はデータと加工ロジックまでで、設置したかまど／溶鉱炉／燻製器／焚き火／石切台／鍛冶台のGUI、スロット移動、ワールド座標ごとの加工状態永続化、マルチプレイ同期までは未接続です。燃料容器返却やcampfireの複数スロットも未対応です。
- クラフトはレシピ一覧とプレイヤー2×2枠を中心とした既存UIです。作業台を開く3×3画面、作業台設置要件、全ての特殊レシピ種別（smithing trim等）のフル実装は未完了です。
- ブロック当たり判定はKoruvaの形状セットに基づく近似。ドア／トラップドア／フェンス接続状態などJava版の全state形状、全ブロックの採掘適正・耐久・ドロップ挙動は一致していません。
- **マルチプレイ**では通常のブロック変更・インベントリ・クラフト・Mob状態・矢の物理処理をサーバー権威にしていますが、加工装置や全エンティティAIの同期が完成したわけではありません。
- TypeScript構文トランスパイルは32ファイルでエラー0。`tsc`の型検査とViteビルドは、作業環境に`@cloudflare/workers-types`および`vite/client`が未導入のため未実行です。
